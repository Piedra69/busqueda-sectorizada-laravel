# HU-01 - Búsqueda sectorizada

**Como** ciudadano,
**quiero** filtrar reportes por sector y tipo de caso,
**para** encontrar rápidamente personas, adultos mayores, mascotas u objetos reportados cerca de mi zona.

## Prioridad
Alta

## Estimación
3 puntos

## Criterios de aceptación

- [ ] Dado que existen reportes activos, cuando selecciono un sector, entonces solo veo reportes de ese sector.
- [ ] Dado que selecciono un tipo, cuando realizo la búsqueda, entonces solo veo reportes de ese tipo.
- [ ] Dado que selecciono sector y tipo, ambos filtros se aplican al mismo tiempo.
- [ ] Dado que escribo una palabra clave, se buscan coincidencias en título y descripción.
- [ ] Dado que no existe coincidencia, se muestra un mensaje claro de “No se encontraron resultados”.
- [ ] Dado que no selecciono filtros, se muestran todos los reportes activos.
